# Revenue Performance Dashboard

Built in collaboration with Claude (Anthropic) as the AI development partner. All product decisions, design direction, data architecture, and deployment were led by [Giani Michael](https://www.linkedin.com/in/giancarlomichael/).

## Overview

A fully interactive business intelligence dashboard built from scratch using HTML, CSS, and vanilla JavaScript — no frameworks, no dependencies.

## Features

- Q1–Q4 tab navigation with independent data per quarter
- Live quota attainment tracking with 8-tier commission payout calculator
- SPIFF tracker that rolls into total revenue and attainment
- Quarter-over-quarter comparison with growth indicators
- Annual run rate projector with bar chart visualization
- Persistent data layer via Airtable API integration
